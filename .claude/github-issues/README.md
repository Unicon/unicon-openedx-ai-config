# GitHub Issues Cache

Local cache of GitHub issue descriptions from `openedx/openedx-core` and
`openedx/openedx-platform`, organized by workstream and epic, so ticket drafting doesn't
need to re-fetch from GitHub every time.
**GitHub is the source of truth for everything in it** — see each workstream's own README
for the details on how stale this cache can get and what it deliberately leaves out.

The issue text in this folder is reproduced from those repositories for reference. The
upstream issues are the source of truth for that text. Reproduced third-party material
remains subject to its applicable terms and is not relicensed by this repository.

- [`competency-criteria/`](competency-criteria/README.md) — 8 epics
- [`student-progress/`](student-progress/README.md) — 6 epics
