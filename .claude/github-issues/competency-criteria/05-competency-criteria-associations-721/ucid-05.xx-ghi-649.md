# [Release Docs] Docs for competency criteria associations to courses

GitHub: https://github.com/openedx/openedx-core/issues/649 (#649, OPEN)

This issue adds user-facing documentation for associating competency criteria to courses.

Documentation should explain what a competency criteria association is, how a criterion is attached to a piece of content (course final grade or subsection assignment), how the association is configured (rule/threshold), and how it appears to course authors once set. Documentation should follow the same process used for the previous taxonomy editing work, with docs added to the Open edX documentation repository.
