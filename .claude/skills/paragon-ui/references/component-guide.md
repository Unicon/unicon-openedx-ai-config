# Component guide

Two things in one file: the Figma "Paragon Categories" component names → their real
Paragon 23.23.0 exports (generated by `.claude/design-system/scripts/generate.mjs`, in
`.claude/design-system/figma-paragon-map.json`'s `components` array — this file is the
curated, human-readable front end to that data, not a duplicate source of truth), and a
short UI-pattern index for when there's no Figma name to start from.

## Figma name → Paragon export (Paragon 23.23.0; re-check via the map on any Paragon bump)

Most of the 70 names in the catalog's "Paragon Categories" variables match a top-level
export exactly (`Button`, `Alert`, `Card`, `Tabs`, `Modal`→see below, ...). The exceptions:

| Figma name | Real export | Note |
|---|---|---|
| `NavBar` | `Navbar` | |
| `Breadcrumbs` | `Breadcrumb` | |
| `Autosuggest` | `FormAutosuggest` | |
| `Modal` | `ModalDialog` | `Modal` itself isn't exported; Paragon's own docs cover the modal family as `.mdx` pages, not one component |
| `Input` | `FormControl` (via `Form`) | |
| `Input.Inline` | `FormControl`, inline variant (via `Form`) | check `FormControl`'s props for the inline prop name |
| `Checkbox` | `CheckboxControl`, or `FormCheck` for one item in a set (via `Form`) | |
| `Radio` | `RadioControl`, or `FormRadio`/`FormRadioSet` for a set (via `Form`) | |
| `Switch` | `SwitchControl`, or `FormSwitchSet` for a set (via `Form`) | |
| `Form.Control` | `FormControl` (via `Form`) | Figma's dotted name; the real export has no dot |
| `Form.Control.Feedback` | `FormControlFeedback` (via `Form`) | |
| `Form.Group` | `FormGroup` (via `Form`) | |
| `Form.Label` | `FormLabel` (via `Form`) | |
| `IconButton.Toggle` | `IconButtonToggle` | |
| `Multiselect` | **none** | no-equivalent; see `paragon-gaps.md` |
| `ContentBlockEmpty` | **none** | no-equivalent; see `paragon-gaps.md` |
| `ContentBlockError` | **none** | no-equivalent; see `paragon-gaps.md` |

For anything not listed here, confirm against the live map (`grep -F '<name>'
.claude/design-system/figma-paragon-map.md`, `components` section) rather than trusting this
table blindly after a Paragon version bump — it's generated from `src/index.ts`, and a real
rename would show up there.

## UI-pattern index (no Figma name to start from)

| Need | Reach for | Not |
|---|---|---|
| A primary/secondary/tertiary action | `Button`, `IconButton`, `StatefulButton` (async action with a pending state) | A styled `<button>` |
| A dismissible inline message | `Alert` | A custom banner div |
| Non-blocking transient feedback | `Toast` | A custom snackbar |
| A blocking dialog | `ModalDialog` | A hand-rolled overlay + portal |
| A non-blocking side panel | `Sheet` | |
| Brief content on hover/focus, **non-interactive** | `Tooltip` (renders `role="tooltip"` — never put interactive content inside it) | |
| Rich or interactive popup content | `Popover`, or `ModalPopup` if it needs to hold focusable content | `Tooltip` with a button inside it |
| A status/count indicator | `Badge`, `Bubble`, `Chip` | Custom colored `<span>` |
| A data grid with sort/filter/paginate | `DataTable` | A hand-rolled `<table>` |
| A collapsible section | `Collapsible` | Custom show/hide state + CSS |
| A dropdown menu | `Dropdown`, `Menu`, `MenuItem` | |
| Tabs | `Tabs` | Custom tab-switching state |
| Multi-step flow indicator | `Stepper` | |
| An avatar | `Avatar`, `AvatarButton` (interactive) | |
| A progress indicator | `ProgressBar`, `Spinner`, `Skeleton` (loading placeholder) | |
| A carousel | `Carousel`, `ChipCarousel` | |
| A search input | `SearchField` | A bare `Form.Control` with a magnifier icon |
| A single-select with search/filter | `SelectMenu`, `Autosuggest`→`FormAutosuggest` | |
| A card | `Card` (has `Card.Header`, `Card.Body`, etc.) | |
| Responsive layout | `Container`, `Layout`, `Stack` | Hand-written flex/grid CSS for a standard layout |
| Text truncation with a "show more" | `Truncate` | CSS `text-overflow` alone, if interaction is needed |

A pattern genuinely not covered here or in the Paragon exports: check
`.claude/design-system/paragon-gaps.md` for a prior decision before composing something new,
and add a row there once you do.
